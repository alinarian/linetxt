Pick a mode

Every control below is a real parameter of the skill. The code updates with it.

Use it

Copy the skill into your agent's skills directory and name the mode in your request. If you don't name one, the agent asks rather than choosing for you. 

Apply $linetxt typewriter to this heading.
Apply $linetxt line-reveal to this heading.
Apply $linetxt gentle to this heading.

The gentle mode reuses the motion contract published by serega-gentle. serega is not vendored here — if your project installs it, import seregaGentle from it directly.
